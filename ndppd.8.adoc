== Name
ndppd - neighbor advertisement proxy daemon for IPv6

== Synopsis
*ndppd* [ *-dv* ] [ *-c* _config_file_ ] [ *-p* _pid_file_ ] [ *--syslog* ] [ *--netns* _name_ ]

== Description
*ndppd* is a neighbor advertisement proxy daemon; it allows a host to proxy neighbor discovery
messages between interfaces to allow routing of otherwise non-routable IPv6 addresses.
It implements part of *RFC 4861*.

== Options

*-c*, *--config*=_path_::
    Location of the configuration file.
+
Default: /etc/ndppd.conf

*-p*, *--pidfile*=_path_::
    Path to the pidfile. Used in conjunction with *-d* or *--daemon*.

*-d*, *--daemon*::
    Puts the daemon into the background. If *-p* or *--pidfile* has been provided, *ndppd* will lock the
    specified file and write the PID of the newly spawned child to it. The file remains locked until the
    child terminates.

*--syslog*::
    Force the use of syslog even if *ndppd* is not running as a daemon.

*-v*::
    Increase the verbosity of the logging. Multiple *-v* increases the verbosity even further.
    The default level is _info_, which includes _error_ and _warning_; *-v* adds _debug_ and *-vv* adds _trace_.

*--netns*=_name_::
    (Linux only.) Enter the named network namespace, as created by *ip-netns*(8), before opening
    any sockets. The configuration file is read before the namespace is entered.

== Notes

*ndppd* places every proxied interface into promiscuous mode. A unicast _neighbor solicitation_
sent as part of neighbor unreachability detection is addressed to a specific link-layer address,
and will not otherwise be delivered when that address is stale or belongs to another host.

Log output is written with the standard C library, which buffers it when standard output is not a
terminal. Use *stdbuf*(1) with *-oL* to read the log as it is produced.
